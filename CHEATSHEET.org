#+TITLE: Emacs Cheat-Sheet — Christer's Setup
#+AUTHOR: Christer Söderlund
#+STARTUP: showall

Quick reference for the keybindings and commands defined in =config.org=.
Everything here is *custom* to this config unless marked /(built-in)/.
=C-c= = Control+c, =M-x= = Alt+x (run a command by name).

* Go  (go-mode / go-ts-mode)
| Key       | Command                   | Does                                            |
|-----------+---------------------------+-------------------------------------------------|
| =C-c r=     | cs/go-run-file            | Save + =go run= THIS file (compilation buffer)    |
| =C-c c=     | compile                   | Prompt for a build cmd (default =go test ./...=)  |
| =C-c C-c=   | recompile                 | Re-run the last compile command, no prompt      |
| =C-c t t=   | go-test-current-test      | Run the test at point                           |
| =C-c t f=   | go-test-current-file      | Run all tests in this file                      |
| =C-c t p=   | go-test-current-project   | Run the whole project's tests                   |
| =C-c t b=   | go-test-current-benchmark | Run the benchmark at point                      |
| =C-c t g=   | go-gen-test-dwim          | Generate test scaffolding (gotests)             |
| =C-c t a=   | go-tag-add                | Add struct field tags (gomodifytags)            |
| =C-c t r=   | go-tag-remove             | Remove struct field tags                        |
| =C-c t i=   | go-impl                   | Generate interface method stubs                 |

*Tip:* at =C-c c=, edit the suggested command to =go build ./...=, =go vet ./...=,
or =go run .=. After the first run, =C-c C-c= repeats it. Jump between build/test
errors with =M-g n= / =M-g p= (see Diagnostics).

* C / C++  (c-mode, c++-mode, *-ts-mode)
| Key       | Command              | Does                                       |
|-----------+----------------------+--------------------------------------------|
| =C-c c=     | compile              | Build (default =make= if a Makefile exists)  |
| =C-c C-c=   | recompile            | Re-run last compile                        |
| =C-c o=     | cs/clangd-other-file | Switch source ↔ header (via clangd graph)  |

| =C-c f f=   | find-file           | Open a file                             |

| =C-c b b=   | consult-buffer      | Switch buffer (with preview)            |
| =C-x C-b=   | ibuffer             | Buffer list manager                     |
| =C-c j=     | consult-imenu       | Jump to a symbol in the current file    |
| =C-c .=     | embark-act          | Act on the thing at point / candidate   |
| =M-y=       | consult-yank-pop    | Paste from kill-ring with preview       |

* Writing & display  (global)

|---------+------------------+-------------------------------------|

| =C-c s=   | flyspell-mode    | Spell-check toggle                  |

| =C-c -=   | text-scale -1    | Smaller text                        |
| =C-c 0=   | text-scale reset | Reset text size                     |

* LSP — eglot  /(no custom keys; use M-x or defaults)/
Eglot starts automatically in Go and C/C++ buffers (=eglot-ensure=).
| Key / Command          | Does                                          |
|------------------------+-----------------------------------------------|
| =M-.=  /(xref)/          | Go to definition                              |
| =M-,=  /(xref)/          | Jump back                                     |
| =M-?=  /(xref)/          | Find references                               |
| =M-x eglot-rename=       | Rename symbol project-wide                    |
| =M-x eglot-code-actions= | Offer quick-fixes / refactors at point        |
| =M-x eglot-format=       | Format region/buffer via the server           |
| =C-M-i= /(built-in)/      | Trigger completion-at-point manually          |

*Note:* inline gray type hints (inlay hints) are turned OFF in this config.
To re-enable per buffer: =M-x eglot-inlay-hints-mode=.
Format + organize-imports run automatically on save (Go: gofumpt; C/C++: only
if a =.clang-format= exists).

* Diagnostics — flymake  /(built-in)/
Enabled in all =prog-mode= buffers.
| Key       | Command               | Does                              |
|-----------+-----------------------+-----------------------------------|
| =M-g n=     | next-error            | Next error (flymake / compile)    |
| =M-g p=     | previous-error        | Previous error                    |
| =M-x flymake-show-buffer-diagnostics= | List this buffer's issues |

* Completion behaviour  /(automatic, no keys)/
- *Minibuffer:* vertico (vertical list) + orderless (type space-separated
  fuzzy fragments in any order) + marginalia (annotations).
- *In-buffer:* corfu popup appears after 2 chars / 0.1s. =TAB= or =RET= to
  accept, arrows / =M-n= =M-p= to move, =C-g= to dismiss.

* Where things live
| File                         | Purpose                                          |
|------------------------------+--------------------------------------------------|
| =~/.emacs.d/init.el=           | Bootstrap; tangles + loads =config.org=            |
| =~/.emacs.d/config.org=        | *Source of truth* — edit this                      |
| =~/.emacs.d/config.el=         | Auto-generated from config.org (do not hand-edit)|
| =~/.emacs.d/CHEATSHEET.org=    | This file                                        |
| =~/.emacs.d/themes/=           | voidlight theme                                  |

*Editing the config:* change =config.org=, then either restart Emacs (it
re-tangles automatically) or =M-x org-babel-tangle= in config.org followed by
=M-x load-file= on config.el.
